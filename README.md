#  Lavina Personal Website

A modern personal portfolio website built with **Next.js 15**, **TypeScript**, and **Tailwind CSS v4**, showcasing professional achievements, publications, research contributions, mentorship, services, and academic expertise.

##  Features

- Responsive modern design
- Publications & research showcase
- Professional experience timeline
- Mentors section
- Services overview
- Image & video gallery
- Contact page
- SEO-friendly static export
- Optimized for Vercel deployment

---

##  Tech Stack

- Next.js 15
- React
- TypeScript
- Tailwind CSS v4
- Vercel

---

##  Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/themindclaritystudio/lavina_personal_website.git
cd lavina_personal_website
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

##  Production Build

Generate a production build:

```bash
npm run build
```

Preview production build locally:

```bash
npm run start
```
